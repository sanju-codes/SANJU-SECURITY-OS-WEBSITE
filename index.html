[ 06 — PROJECT FAQ ]

QUESTIONS.
ANSWERED.

A quick guide to the project direction, compatibility goals and release status.

Is SANJU SECURITY OS ready to install?＋

The project is in development. Check the main OS repository for verified build instructions and published releases before attempting installation.

Which Linux distribution is the base?＋

The current project target is Debian 13 (Trixie). Desktop components and package selections may change as development progresses.

Will Windows applications work?＋

The direction is a hybrid approach using Wine/Bottles for suitable applications and a Windows virtual machine where full Windows compatibility is required. Compatibility is application- and hardware-dependent.

Does the project support SDR hardware?＋

SDR support is a planned research area. Device support depends on the hardware, drivers and selected software packages.

Where can I report a bug or contribute?＋

Visit the GitHub repository to review the project, open an issue or follow development updates.
