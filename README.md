# SANJU SECURITY OS — Official Website

A responsive project website for SANJU SECURITY OS, a Debian 13-based security, digital forensics and research workstation concept.

## Website
After GitHub Pages deployment: https://sanju-codes.github.io/SANJU-SECURITY-OS-WEBSITE/

## Project
SANJU SECURITY OS is being developed as a unified environment for:
- Cybersecurity learning and authorized security testing
- Digital forensics and evidence examination
- Data recovery workflows
- SDR and RF research with compatible hardware
- Windows application compatibility and virtual machines
- Offline-first lab workflows

**Development note:** This site describes the project vision and planned capabilities. Individual tools, integrations and release images should be considered available only when they are published and documented in the main project repository.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Push changes to `main`, or run the **Deploy website to GitHub Pages** workflow manually from the Actions tab.
4. When the workflow succeeds, visit the website URL above.

## Local preview
Open `index.html` in a browser. The site uses plain HTML, CSS and JavaScript; no build tools or package installation are required.
